当前验收：**使用现有仿真数据，完成 RDF → CTDA → 8 轮训练 → 独立测试 → 权重与结果保存的整条流程。** 按式 (35) 对照 98.33%；数据难度与严格数值复现作为后续改进，不再作为进入训练的前置条件。

## 已落实的数据选择

表 2 的初始速率 200–1500 m/s、初始俯仰/偏航 ±π/2、加速度幅值 0–10 m/s²、目标数 1–25、漏检 .1、Poisson 杂波均值 20 保留。其余首轮选择如下，均为**补全假设，不是作者原始数据配置**：

| 未报告项 | 本轮执行选择 |
|---|---|
| 2000 trajectories 的单位 | 2000 个独立多目标场景；每场景有 1–25 条真实目标轨迹 |
| 时间 | 101 帧，Δt=1 s，100 个相邻帧量测关联对 |
| 空间 | 初始 x/y 均匀 ±100 km，z 均匀 0–100 km；依据图 9 的量级；每轴检测界限 ±1000 km |
| 运动控制 | 分段恒定三维加速度，幅值 U(0,10)，每 10 s 更新；通过局部投影与重力补偿换算成式 (1) 的控制量，保存控制和六维状态 |
| 过程噪声 | Q=0，避免猜测论文未报告的强度；非零 Q 后续单列敏感性实验 |
| 观测噪声 | 两个并列候选：式 (2) 距离 σ=1000 m、角噪声为 0；或笛卡尔三坐标独立 σ=1000 m。共享真值、漏检与杂波 |
| 杂波 | 均匀分布；主数据 x/y ±200 km、z −150–250 km；每帧独立 Poisson(20)，不加真实目标 ID |
| 数据划分 | 先固定场景级 1800/200；1800 内暂分 1620 训练、180 验证，200 测试封存，最终配置固定后可用全部 1800 训练 |
| 配对与标签 | 相邻帧量测到量测；仅同场景同真实目标 ID 为正类；每帧打乱顺序 |
| RDF | 式 (6)–(7)，ε=1 m（三轴相同）；全矩阵归一化后分成 40×40 块；原始数据永久保留，ε 可以重算 |
| 随机性 | NumPy PCG64，主种子 20261013；场景种子独立，固定划分 |

控制补全使式 (1) 能执行，但其分布未经作者确认；实际加速度的 U(0,10) 不能等同于作者控制变量的未知采样规则。首轮目标数在一个场景内固定，出生/死亡留到完整跟踪阶段。

## 执行顺序与验收

1. **先获得数据。**生成上述 2000 场景，保存状态、位置、极坐标观测、两种噪声位置、漏检、杂波、稀疏关联真值、划分和参数。另生成 100 个独立汇聚交叉诊断场景，检查主数据是否过于容易，不混入训练或封存测试。
2. **立即检查数据。**检查有限值、式 (1) 的运动/控制一致性、式 (2) 坐标往返、噪声标准差、漏检率、杂波均值、标签一对一性、划分无重叠；在验证集与交叉诊断集跑固定距离匹配基线，制作代表性图。检查通过才训练。
3. **直接训练 CTDA。**使用已有距离噪声版数据，首轮只跑一个种子。40 维、4 heads、行列 2 层/通道 1 层、FFN=160、ReLU、dropout=.3、逐元素融合、无位置编码；按公式保留交叉 Q/K/V 和残差位置。α=.75、γ=2、Adam 1e-4、batch=256、8 epochs。padding 元素作负标签，优化损失取每块元素均值。还原全矩阵后作允许未匹配的全局匹配，阈值 .2；每轮报告验证 loss、论文 Accuracy 和正关联 F1。
4. **完成测试并交付。**使用固定第 8 轮权重评价全部 200 个测试场景，保存最终/最佳验证权重、训练曲线、逐轮指标、测试关联示例和简短报告。测试集不参与阈值和配置选择。

第 3 步中的隐藏维度、FFN 和归约属于实现假设，保存在运行配置中。主数据较简单这一发现保留在报告中，不阻止首轮训练；完成流程与达到严格论文复现要求分别记录。

**执行进度：数据生成、核验和最小难度核查已完成。**2000 场景、20 万关联对已落盘；固定 180 验证场景上的 84 个配对条件确认主数据过于稀疏。只拉近目标能产生真实错配；只集中杂波会导致大量杂波间假匹配。这两类困难必须分别控制。结果见 [难度核查](../results/data_difficulty_v1/REPORT.md)。

**当前结果：首轮完整流程已完成。**CTDA 前向、全部参数梯度、一对一匹配、RDF 缓存和重新加载权重推理检查通过；按第 3–4 步完成 8 轮训练及 200 场景/2 万配对测试，训练与评价约 9.81 分钟。测试 Accuracy 69.43%，正关联 F1=0，模型发生未匹配退化，尚未达到论文结果。[权重与结果报告](../results/ctda_first_run/REPORT.md)。

**第二轮修正已完成：**相同数据、同种子重新训练 8 轮，排除 padding 损失并补全通道 decoder 残差，保留 α=.75、γ=2 Focal Loss。完整测试 Precision 45.56%、Recall 93.37%、F1 61.24%，全零退化解除，假匹配仍需处理。[结果与权重](../results/ctda_repaired_run/REPORT.md)。

已单独测试行列分类与匹配数量惩罚，较强惩罚在小样本上提高 Precision、降低 Recall；这些未在原论文报告，保留为诊断，不混作严格复现训练。[损失/残差/约束对照](../results/ctda_collapse_diagnosis/REPORT.md)。后续优先继续排查残余假匹配和论文网络实现的细节。

## 下一轮最小诊断计划

**当前优先执行轮次对照：**第 6–8 轮验证 Accuracy 从 51.45% 持续升至 63.68%，尚无明显平台。先恢复第 8 轮模型及 Adam 状态，续训到固定总计 20 轮；保持 batch=256、lr=1e-4、损失、数据和阈值 .2 不变。每轮评估同一训练子集（64 个 fit 场景、640 对）及验证集，使用 eval 模式和同口径指标。旧检查点缺少 RNG 状态，随机序列重新初始化并记录；本轮保存 RNG 便于后续准确恢复。20 轮在训练前固定，最终测试只在终点执行。8 轮结果保留作论文设置对照，延长轮次属于收敛诊断。

**20 轮对照已完成并核验。**完整测试 Accuracy 91.39%、Precision 78.27%、Recall 98.48%、F1 87.22%；较第 8 轮 Accuracy 提高 27.37 个百分点。固定训练子集与验证 Accuracy 分别为 91.77%、91.49%，未见明显泛化差距。恢复 Adam、源文件快照和从原始测试配对 CPU 重载检查均通过。[20 轮报告](../results/ctda_extended_20/REPORT.md)。

**30 轮续训已完成并核验。**延长决定依据第 18–20 轮验证 Accuracy 87.20%→89.59%→91.49%，有效区域验证 Loss 0.000566→0.000495→0.000448；恢复第 20 轮模型、Adam 和已保存的 RNG 状态，其他设置不变。30 轮预先固定，最终测试不用于轮次选择。完整测试 Accuracy 96.04%、Precision 88.73%、Recall 99.78%、F1 93.93%；固定训练子集和验证 Accuracy 为 96.21%、96.17%，未见明显过拟合。CPU 原始配对重载和源文件哈希检查通过。提升已放缓，仍不能宣称完全收敛或严格复现论文 8 轮结果；下面的误匹诊断作为后续优先事项。[30 轮报告与权重](../results/ctda_extended_30/REPORT.md)。

**按用户要求追加十轮：第 30→40 轮已完成并核验。**保持其他设置不变，仅用验证曲线判定是否接近平台，本轮固定在 40 轮结束。完整测试 Accuracy 97.20%、Precision 91.78%、Recall 99.86%、F1 95.65%；验证 Accuracy 30→40 增加 1.190 个百分点，35→40 仍增加 0.476，F1 同期增加 0.711 个百分点。按[预定协议](epoch_saturation_protocol.md)尚未满足平台判据，收益已明显变小。训练子集与验证 Accuracy 为 97.35%、97.36%，CPU 原始配对重载、Adam 总更新步数 34,720 及源文件哈希核验通过。[轮次对照和判定报告](../results/ctda_epoch_comparison/saturation_report.md)。[组会文件计划表](group_meeting_file_plan.md)已列明现有材料、待补图表、幻灯片与 PDF 等计划文件。

1. **固定数据与第二轮权重，定位假匹配。**在现有 180 个验证场景上统计杂波—杂波、目标—杂波、错误目标—目标三类假匹配，以及正确/错误边的分数和行列排序。分别判断真值边没有排到前列，还是未匹配行列被错误接受。
2. **验证匹配决策。**仅在验证集比较阈值与未匹配代价对 Precision、Recall、F1 和式 (35) Accuracy 的影响。保留论文阈值 .2 的原结果；其他设置作为诊断单列。当前分配采用概率和最大化、未匹配收益为 0，接受假匹配的代价可能不足，此项尚待实验证实。
3. **按诊断决定重训。**若排序正确但拒配错误，优先核对论文阈值及匹配步骤；若排序本身错误，先用少量固定训练场景验证能否过拟合，再逐项核对 Q/K/V、padding 注意力和未报告的网络维度。新增惩罚作为消融，不直接替代论文训练目标。配置在验证集确定后，再做完整训练和最终测试；不以反复查看测试结果选择参数。

本轮不重新仿真数据。现有数据距离基线 Accuracy 为 99.90%，先解决同一数据上的模型/匹配差距；更难数据留到这一问题查清之后。
