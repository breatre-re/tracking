## 3. 实验规格：可用明确假设启动，严格等价仍受限制

论文已经提供主要方法、运动方程、标签定义、40×40 分块、4 heads、dropout=.3、Adam 1e-4、8 epochs、batch=256、Focal α=.75/γ=2，以及 3D 关联阈值 .2。这些足够构建有依据的实验骨架。

首轮实施前必须把下列选择写成可执行配置：

| 优先级 | 内容 | 如何处理 |
|---|---|---|
| P0：数据含义 | “2000 trajectories” 的单位、序列长度、Δt、D1/D2 配对和间隔 | 明确自己的解释并标为复现假设；未确认前不能当成作者设定 |
| P0：数据难度 | 初始位置、目标间距、控制时序、过程噪声、1000 m 观测噪声的坐标解释、杂波分布 | 给定可审计配置；保存真值及统计量；比较噪声、帧间位移与目标间距 |
| P0：网络细节 | RDF ε、隐藏维度、FFN、交叉注意力接线、残差与共享方式 | 依据公式和图 3 选择主实现；争议项可做少量敏感性对照 |
| P0：训练评价 | padding loss、loss reduction、Accuracy 汇总、KM 修正、未匹配处理 | 在训练前固定口径，避免靠错误指标获得高分 |
| P1：完整稳健性曲线 | false rate 定义、图 7 噪声横轴冲突、统计重复方式 | 不妨碍首轮训练，影响完整复现图 5–8 |
| 完整系统阶段 | BLUE、评分、确认/删除、出生死亡、2D 通道适配 | 若首轮做相邻帧量测关联可后置；若输入滤波预测则需先解决相应依赖 |

最大的科学风险是数据难度不等价。例如在很大空间内均匀放置少量目标，目标距离可能远大于噪声和帧间位移，使简单距离匹配也接近满分。此时 CTDA 高准确率不足以说明复现了论文的挑战条件。

严格复现还缺作者真实配对策略、数据量、完整网络实现和指标归约。可以在记录假设的前提下继续推进；仅达到 98.33% 或 0.0067 不能消除这些可比性问题。

## 4. 下一轮实验的建议范围

1. **冻结首轮规格。**优先做 3D 相邻帧量测关联，明确这是首轮范围；用目标 ID 生成标签，保留漏检和杂波，不使用测试集选配置。
2. **先打通可检查的数据与评价。**验证标签、分组划分、分块还原和一对一匹配；同时跑距离匹配基线。
3. **小数据训练检查。**检查损失下降、正关联恢复、梯度和过拟合能力，排除全零预测及 padding 造成的虚高。
4. **再扩大到论文训练方案。**配置稳定后按 8 epochs、batch=256 运行，保留独立测试场景，报告论文 Accuracy、正关联 precision/recall/F1 和实际资源用量。
5. **之后增加稳定性证据。**至少 3 个独立训练种子、关键消融和噪声/漏检/杂波扫描；5 折分组验证可作为后续扩展，不必成为启动首轮的前置条件。

目前适合开始第 1–3 步。进入规模训练前，应能回答：一个样本代表什么、训练/测试是否共享底层轨迹、全零预测会得到多少分、简单距离基线有多强、Loss 的归约方式是什么。
